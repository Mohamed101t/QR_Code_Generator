# 📱 صانع رموز QR المتقدم | Advanced QR Code Generator

تطبيق سطح مكتب احترافي وبواجهة حديثة لبناء وتخصيص طباعة وتصدير رموز الـ QR ذات الاستخدامات المتعددة. تم تطوير البرنامج باتباع معمارية **Clean Architecture** المتقدمة مع دعم كامل لعدة لغات وأنظمة تشغيل.

---

## 🌟 مميزات التطبيق (Features)

1. **دعم أنواع محتوى متعددة:**
   * **نص فقط (Plain Text):** تحويل النصوص العادية البسيطة مباشرة.
   * **معلومات شخصية / بطاقة أعمال (Digital Card):** نظام ذكي يحول إدخالات المستخدم (الاسم، الوظيفة، الهاتف، الرابط) تلقائياً إلى بطاقة أعمال أنيقة ومنسقة بلغة عربية نظيفة ومقروءة على أي هاتف بدون رموز برمجية مزعجة.
   * **روابط (URL / Image / Video):** تحويل كافة أنواع الروابط الخارجية مباشرة.

2. **تخصيص كامل للتصميم (Customization):**
   * تغيير ألوان الرمز والخلفية عبر أداة اختيار الألوان (Color Picker).
   * اختيار شكل النقاط الداخلية للرمز: مربعات حادة (`Square`)، حواف دائرية (`Rounded`)، أو نقاط دائرية (`Circle`).
   * التحكم في انحناء حواف خلفية بطاقة الرمز (`Card Radius`).

3. **دعم متعدد اللغات (Multilingual):**
   * دعم كامل لـ 6 لغات مع تبديل لحظي: العربية، الإنجليزية، الصينية، الفرنسية، الروسية، الهندية.

4. **المعاينة اللحظية والتصدير (Live Preview & Export):**
   * تحديث شكل الرمز تلقائياً مع كل عملية كتابة أو تعديل خيارات.
   * إمكانية حفظ الرمز بصيغة صورة عالية الدقة `PNG`.
   * إمكانية طباعة الرمز مباشرة عبر الطابعة المتصلة.

## 🏗️ المعمارية الهندسية (Clean Architecture)

تم تقسيم كود المشروع إلى طبقات مستقلة تماماً لضمان سهولة الصيانة والتطوير المستقبلي:

* **`lib/core/`**: تحتوي على الخدمات المشتركة مثل الألوان والتصميم (`theme/`) وخدمة إدارة اللغات والتراجم (`localization/`).
* **`lib/features/qr_generator/domain/`**: طبقة قواعد العمل والكيانات الأساسية (`Entities`, `UseCases`, `Repositories Interfaces`).
* **`lib/features/qr_generator/data/`**: طبقة معالجة البيانات وبناء صورة الرمز فعلياً عبر مكتبات Python (`DataSources`, `Repositories Implementation`).
* **`lib/features/qr_generator/presentation/`**: طبقة واجهة المستخدم وتستند إلى `CustomTkinter` بالإضافة لموجه الحالة `QRNotifier`.

## 🧪 حزمة الاختبارات الشاملة (Test Suite)

يحتوي المشروع على 5 أنواع من الاختبارات للتحقق من صحته:

1. **`test_unit.py` (Unit Testing):** اختيارات وحدة للتحقق من صياغة بطاقات المعلومات بدقة.
2. **`test_integration.py` (Integration Testing):** اختبار التكامل بين طبقة البيانات ومحرك توليد الصور.
3. **`test_performance.py` (Performance Testing):** قياس كفاءة توليد 50 رمز QR متتالي في أقل من ثانيتين.
4. **`test_security.py` (Security Testing):** فحص حماية التطبيق ضد المدخلات الخبيثة والحمولات الكبيرة.
5. **`test_e2e.py` (End-to-End Testing):** اختبار كامل لدورة حياة توليد الرمز داخل التطبيق.
